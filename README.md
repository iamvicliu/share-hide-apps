# 共享时隐身（macOS）

简体中文 | [English](README.en.md)

屏幕被采集时自动隐藏你指定的应用，避免会议共享、录屏或演示时露出微信、钉钉等窗口。

- 共享 / 录屏开始时：自动隐藏你选定的应用。
- 隐藏哪些应用由你自己配置，默认不隐藏任何应用。
- 快捷键 ⌃⌥H 立即隐藏，不用等检测到共享。
- 可选：共享时用壁纸盖住桌面图标，结束后自动恢复。
- 可选：开启勿扰模式，结束后自动恢复。

## 安装

打开「终端」，粘贴下面这行并回车：

```bash
curl -fsSL https://raw.githubusercontent.com/iamvicliu/share-hide-apps/main/install.sh | bash
```

装好后会弹出配置窗口，把要隐藏的应用加进去即可，设置立即生效，之后开机自动运行。

> 介意 `curl | bash` 的话，可以先把 [install.sh](install.sh) 和源码（[main.swift](main.swift)、[sharewatch.swift](sharewatch.swift)、[config-gui.swift](config-gui.swift)）看一遍再运行。

## 添加要隐藏的应用

![配置窗口](docs/config-window.png)

安装后，点菜单栏图标里的「打开配置…」，或打开 `~/Applications` 里的「共享时隐身」，就能管理。左边是要隐藏的应用，右边是正在运行的应用。三种方式添加：

1. 在右边「正在运行」里点「添加」（最省事，想隐藏的应用通常都开着）。
2. 把应用从「访达」拖到左边列表。
3. 点左边的「从『应用程序』选择…」挑选。

## 快捷键立即隐藏

按 ⌃⌥H，左边的应用马上隐藏，不用等检测到共享。适合共享前先手动收一下，或者检测没生效的时候用（见下方「已知限制」）。菜单栏图标里也有「立即隐藏」。

想换快捷键：在配置窗口右下角点一下快捷键框，按下新的组合键；点 ✕ 清除，点「恢复默认」改回 ⌃⌥H。快捷键要带上 ⌃ 或 ⌥。

## 隐藏桌面图标

勾选配置窗口左下角「共享时」下面的「隐藏桌面图标」，共享时桌面上的文件和小组件会被壁纸盖住，共享结束后自动恢复。勾选和取消都立即生效，默认关闭。

共享中途想让桌面图标露出来，有两种办法：

- 在桌面空白处右键，选「显示桌面图标（仅本次）」；选「以后共享时不再隐藏桌面图标」则直接关掉这个功能。
- 点菜单栏图标，选「显示桌面图标」，再点一次可以重新隐藏。

「显示」只对这一次共享有效，下次共享开始时会照常盖住。盖住期间点桌面不会打开下面的文件，也不能往桌面上拖文件。

## 共享时开启勿扰

勾选「共享时」下面的「开启勿扰模式」，共享开始时自动打开勿扰，结束后自动关闭。默认关闭。

macOS 不让普通程序直接开关勿扰，所以要借助一个快捷指令。第一次勾选时会提示「还没添加快捷指令」：

1. 点「添加快捷指令…」，系统会打开「快捷指令」App。
2. 在弹出的窗口里点「添加快捷指令」。之后就不用再管了。

这个快捷指令名叫「共享时隐身 勿扰」，里面只有「打开 / 关闭勿扰模式」两个动作，可以在「快捷指令」App 里打开查看。

注意：如果共享前你已经自己打开了勿扰，共享结束时它也会被关掉。

## 菜单栏图标

安装后，菜单栏右上角会出现一个眼睛划线图标。点开可以看当前状态、打开配置窗口，或退出程序。

- 关掉配置窗口（点左上角 ✕）只是收起窗口，程序照常工作，菜单栏图标还在。
- 从菜单栏图标的菜单里选 退出「共享时隐身」，或在配置窗口里按 ⌘Q，才是真正退出。退出后再打开「共享时隐身」即可恢复，下次登录也会自动启动。

## 注意事项

- 任何会议、录屏软件触发屏幕采集都会生效，不区分是哪一款软件。
- 建议在「系统设置 → 通知」里关掉「镜像或共享显示器时允许通知」，双重保险。

## 卸载

```bash
curl -fsSL https://raw.githubusercontent.com/iamvicliu/share-hide-apps/main/uninstall.sh | bash
```

## 适用环境

macOS 12 及以上，Intel 与 Apple 芯片均可。界面跟随系统语言显示中文或英文。

## 技术细节

### 原理

程序每秒调用一次系统接口判断屏幕是否正在被持续采集（会议共享、录屏会触发），连续两次判定为「正在采集」就隐藏你配置的应用。纯本地运行，不联网、不读取任何窗口内容、不收集数据。

配置文件保存在 `~/Library/Application Support/ShareHideApps/apps.conf`，每次开始共享时重读，改完即时生效。

勿扰快捷指令 `focus.shortcut` 由 [tools/make-focus-shortcut.py](tools/make-focus-shortcut.py) 生成并签名。程序运行 `shortcuts run "共享时隐身 勿扰"`，输入 `on` 或 `off`。

### 自己编译

仓库里的 `ShareHideApps` 是预编译的通用二进制（Intel + Apple 芯片，ad-hoc 签名），菜单栏图标、共享检测和配置窗口都在这一个程序里。想自己编译：

```bash
swiftc -O -target arm64-apple-macos12  main.swift sharewatch.swift config-gui.swift -o sha-arm64
swiftc -O -target x86_64-apple-macos12 main.swift sharewatch.swift config-gui.swift -o sha-x86
lipo -create sha-arm64 sha-x86 -output ShareHideApps && codesign -s - --force ShareHideApps
```

### 已知限制

- 用的是 macOS 的系统私有接口 `CGSIsScreenWatcherPresent`，系统大版本升级后可能需要更新。
- 只在「开始被采集」的那一刻隐藏一次。如果有程序一直在看屏幕（比如 AI 助手的「操控电脑」功能），系统会一直报告「正在采集」，之后真正开始共享时就不会再触发自动隐藏。这时请用快捷键手动隐藏。
- 隐藏桌面图标是用一层壁纸盖住桌面，不改访达设置。动态壁纸只能取到其中一张画面，可能和当前显示的稍有差别。
